### 🚀 Featured Projects

**[Enterprise Retail Analytics — Medallion Pipeline](#)**
End-to-end Medallion Architecture pipeline on Azure Databricks: ADF ingestion, ADLS Gen2, Unity Catalog, Delta Lake, SCD Type 2 dimensions, incremental MERGE loads, and RFM customer segmentation. Includes a full Gold layer with `dim_date`, `dim_product`, `dim_customer` (SCD2), `fact_sales` (watermark incremental loads, currency conversion), and JDBC publish to Azure SQL.

**MedCare Analytics — Healthcare Lakehouse**
Lakehouse capstone (Landing → Bronze → Silver → Gold) built with PySpark and Unity Catalog across 10 source tables, with custom Silver-layer logic for legacy time parsing, foreign-key flagging, and null handling on PII fields.

**Job Application Autofill Tool**
Python + Selenium tool that autofills job applications using fuzzy label matching and a persistent Chrome profile, stopping before final submission for manual review.
